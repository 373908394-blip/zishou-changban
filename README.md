# 字守长坂 · 文字合成塔防（Web HTML5 垂直切片）

## 1. 项目简介
对标《赵云与阿斗》的 **Web HTML5 单人闯关 PvE 文字合成塔防** 垂直切片，暂定名 **《字守长坂》**。
汉字即作战单位：汉字即兵、拖合生将、守住阿斗。零依赖、零构建，单文件 `index.html` 双击即可运行。

## 2. 如何运行
- **最简单**：直接双击 `index.html`（或浏览器打开 `file://…/index.html`）。零依赖、零构建，无需服务器 / npm。
- **想用本地服务器**（可选）：在项目根目录执行 `python3 -m http.server`，再访问终端提示的端口（如 `http://localhost:8000/`）即可。

## 3. 操作说明
1. **菜单**：点「开始游戏」或「玩法说明」；可勾选「减弱动效」降低字形形变与技能特效。
2. **选关**：选择「长坂坡」或「赤壁」（切片默认全解锁）。
3. **备战**：
   - 点「征兵」花费 **3 馒头** 随机抽一个汉字（刀/枪/弓/骑为基础兵种，赵/云等为名将碎片）。
   - 把字拖到战场空格布防；拖 **两个同字同阶** 的单位到一起 → 升一阶（t1→t2→t3，伤害倍增）。
   - 把 **赵 + 云** 两碎片互拖 → 合成强力武将「赵云」。
4. **出战**：点「出战」后敌军按波次来袭，单位自动攻击沿路而来的敌军，击杀掉馒头、漏怪扣阿斗血。
5. **技能**：赵云就绪后，点武将本身或底部「贯穿」键，沿直线穿透多怪并结算 `damage×3`，进入冷却读秒。
6. **暂停**：点「暂停」冻结全场逻辑与计时；可重试本关或退出选关。

## 4. 核心特性（对应需求四大模块）
- **关卡与路线设置**：长坂坡（12×8 / TILE64）与赤壁（12×9 / TILE56）双地图，网格路径 waypoints 渲染、路径格高亮且禁建，怪物沿路径行进直扑阿斗据点。
- **文字动效**：刀/枪/弓/骑 四兵种攻击各有可辨识字形形变（弧/刺/拉/冲），受击抖动 + 朱红描边，弓兵发射可见墨箭弹道。
- **技能特效**：赵云可由「赵+云」合成，「贯穿」技能直线墨痕横扫 + 字形突进 VFX，命中整行/列多怪并进入冷却恢复。
- **文字与怪物模块**：`UNIT_DEFS` / `MONSTER_DEFS` 为纯数据表（4 基础兵种 + 3 怪物 + 1 Boss），数据驱动、加内容只改配置不动逻辑；馒头经济闭环（初始 12 / 击杀掉落 / 波次 +4 / 过关 +10）。
