# 字守长坂 · 文字合成塔防（Web HTML5 垂直切片）

## 1. 项目简介
对标《赵云与阿斗》的 **Web HTML5 单人闯关 PvE 文字合成塔防** 垂直切片，暂定名 **《字守长坂》**。
汉字即作战单位：汉字即兵、拖合生将、守住阿斗。零依赖、零构建，单文件 `index.html` 双击即可运行。

- **在线直接玩**：打开 <https://373908394-blip.github.io/zishou-changban/>，无需安装。

## 3. 操作说明
1. **菜单**：点「开始游戏」或「玩法说明」；可勾选「减弱动效」降低字形形变与技能特效，勾选/取消「音效」控制提示音。
2. **选关**：选择「长坂坡」或「赤壁」（切片默认全解锁）。
3. **备战**：
   - 点「征兵」花费 **3 馒头** 随机抽一个汉字（刀/枪/弓/骑为基础兵种，赵/云/张/飞/黄/忠为名将碎片）。
   - 把字拖到战场空格布防；拖 **两个同字同阶** 的单位到一起 → 升一阶（一阶→二阶→三阶，伤害倍增）。
   - 把 **赵+云 / 张+飞 / 黄+忠** 两碎片互拖 → 合成对应两字武将（赵云 / 张飞 / 黄忠）。
   - **每个单位右下角有阶数角标**（1/2/3…），一眼看清等级；拖拽时若可合成，目标格会高亮并提示「同字升阶 / 合成·武将 / 武将升阶」。
4. **出战**：点「出战」后敌军按波次来袭，单位自动攻击并播放各自字形动效（刀挥砍、枪突刺、**弓拉伸蓄力射箭**、骑冲锋扬尘），命中迸溅墨点。
5. **技能**：武将就绪后，点武将本身或底部技能键释放，进入冷却读秒：
   - **赵云·贯穿**：沿直线墨痕横扫，整行/列穿透 `damage×3`。
   - **张飞·眩喝**：以自身为中心圆形震波，`damage×1.5` 并定身敌兵。
   - **黄忠·箭雨**：对目标区域落下多箭，范围 `damage×2`。
6. **武将喂升**：把 **任意一个字**（兵种/碎片均可）拖到两字武将身上 → 武将升一阶（伤害随阶提升，最高 5 阶）；武将也可与武将互合升阶。
7. **暂停**：点「暂停」冻结全场逻辑与计时；可重试本关或退出选关。

## 4. 核心特性（对应需求四大模块）
- **关卡与路线设置**：长坂坡（12×8 / TILE64）与赤壁（12×9 / TILE56）双地图，网格路径 waypoints 渲染、路径格高亮且禁建，怪物沿路径行进直扑阿斗据点。
- **文字动效**：刀/枪/弓/骑 四兵种攻击各有强烈可辨识字形形变（刀挥砍弧光、枪拉伸突刺、**弓文字拉伸蓄力后回弹射箭**、骑前冲扬尘），命中迸溅墨点；受击抖动 + 朱红描边；箭矢为带箭杆/箭羽/拖尾的墨箭。
- **技能特效**：三名两字武将各具独立 VFX —— 赵云「贯穿」直线墨痕横扫、张飞「眩喝」圆形震波 + 定身、黄忠「箭雨」区域多箭下落；技能命中带**顿帧（hit-stop）**冲击，拖拽/合成/升阶均有浮字与高亮反馈。
- **音效**：零素材 WebAudio 合成——出击、四兵种攻击、命中、合成、武将合成、三技能、胜负均有提示音（菜单/暂停可关闭）；多单位齐攻自动节流防嘈杂。
- **减弱动效适配**：开启后关闭字形形变/刀弧/骑尘、震波扩散、箭雨下落与技能突进，浮字不位移，但保留受击红闪、弹道与静态提示（尊重前庭敏感）。
- **文字与怪物模块**：`UNIT_DEFS` / `MONSTER_DEFS` 为纯数据表（4 基础兵种 + 3 武将 + 3 怪物 + 1 Boss），数据驱动、加内容只改配置不动逻辑；馒头经济闭环（初始 12 / 击杀掉落 / 波次 +4 / 过关 +10）。
