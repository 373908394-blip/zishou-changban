# 概念文档 ·《字守长坂》（暂定名）

> 垂直切片定位：Web HTML5 单人闯关 PvE 文字合成塔防，对标《赵云与阿斗》，lean 评审用可玩原型。
> 一句话：**汉字即作战单位，拖合生将，守住阿斗过一关。**

---

## 1. 游戏支柱（Design Pillars）

三条支柱互相支撑，任何功能决策须回扣至少一条，否则砍掉。

| # | 支柱 | 含义 | 落地表现 |
|---|------|------|----------|
| P1 | **字以载战** | 汉字即单位，字形即动作；可读性即上手门槛 | 每个兵种/武将是一个大汉字；攻击时字形按字义形变（弓→拉弓、刀→挥砍）。玩家"读"即"懂"，零教学成本。 |
| P2 | **拖合生将** | 合成是核心乐趣与成长线 | 同字拖合升阶（刀→刀二阶→刀三阶）；名将对子组合出武将（赵+云=赵云）。拖拽即"爽点"。 |
| P3 | **一局一刻** | 3–8 分钟碎片爽感 | 单关多波次、据点守卫的紧张节奏；水墨国风的"静中有躁"。随时能开、随时能收。 |

**支柱冲突红线（设计理论自检）：**
- 杜绝**主导策略**：合成（P2）与布防走位（空间策略）须同等重要，不能"只合不解"通关。
- 杜绝**经济失衡**：馒头（资源）产出/消耗须有闭环公式，避免无限滚雪球或长期枯竭。
- 杜绝**认知过载**：屏幕上同时可读的汉字单位 ≤ 12 个；技能按钮 ≤ 3。
- 杜绝**支柱漂移**：不做联机对战、不做抽卡付费、不做开放世界——均偏离 P3 与单人 PvE 范围。

## 2. MDA 框架分析

### Mechanics（机制层）
- 网格战场（grid battlefield）+ 怪物固定 waypoints 路径。
- 馒头经济：征兵（gacha 抽字）/ 击杀掉落 / 波次与过关奖励。
- 文字合成：同字升阶（tier 1→3）+ 名将对子组合（hero recipe）。
- 单位属性：射程/伤害/攻击间隔/近战or远程/是否发射弹道。
- 武将技能：CD 触发，主动释放（贯穿/眩晕/箭雨）。
- 据点（阿斗）HP；漏怪扣血；阿斗归零=失败；清完所有波次=胜利。

### Dynamics（动态层）
- 玩家在"现在花馒头征兵/合成" vs "囤馒头应对后期波次"之间权衡。
- 在路径咽喉格（转弯、长直道）附近布防形成集火；不同兵种搭配产生协同（弓远程覆盖 + 刀近战补漏）。
- 合成路径选择：升阶堆数值 vs 凑名将对子换技能，形成 build 多样性。

### Aesthetics（美学层，玩家预期体验）
- **Sensation**：水墨宣纸底 + 墨笔汉字 + 字形动效 + 红色印章点缀。
- **Challenge**：守据点的紧张与通关成就感。
- **Discovery**：探索合成配方（赵云之外还有张飞、黄忠）。
- **Expression**：自由布防布局即个性化策略表达。
- **Submission**：水墨禅意的"放松型专注"。

## 3. 玩家心理映射

- **自我决定论（SDT）**：
  - 自主性 Autonomy：布防位置、合成选择、技能释放时机由玩家决定。
  - 胜任感 Competence：升阶/合成/过关都有即时正反馈（字形形变、数字跳变、过关印章）。
  - 关联感 Relatedness：赵云、张飞、黄忠等国民级三国 IP 天然唤起情感联结。
- **Bartle 玩家类型**：以 **Achiever（成就型，清关/集将）** 与 **Explorer（探索型，挖配方）** 为主；单人 PvE 下 Killer / Socializer 权重低，不作针对性设计。

## 4. 范围分层（Scope Layering）

### MUST — 垂直切片（本交付目标，必须可玩）
- 1–2 张地图：长坂坡（含）、赤壁（含，路径不同）。
- 网格战场 + waypoints 路径 + 多波次 spawn + 过关/失败条件。
- 馒头经济闭环（征兵/掉落/奖励）。
- 合成：同字升阶（1→3 阶）+ 赵云配方（赵+云）。
- 4 基础兵种（刀/枪/弓/骑）+ 3 类怪物（小兵/盾兵/飞骑）+ 1 Boss（曹将）。
- 1 武将（赵云）+ 其技能（贯穿）+ 技能特效。
- 文字动效：4 兵种攻击/受击字形形变。
- 流程：关卡选择 → 备战/对局 → 结算。
- 数据驱动：units / monsters / maps 均为配置表，易扩展。

### SHOULD — 目标版（切片验证后补）
- 张飞（眩晕）、黄忠（箭雨）武将与技能。
- 第 3–4 张地图（街亭/麦城），差异化路径与机制（水面减速、火攻区）。
- 怪物更多样（法术兵、治疗兵），兵种克制。
- 单位升级树 / 关卡星级评价。

### COULD — 愿景版（远期）
- 20+ 武将图鉴与组合技。
- 轻剧情弧（长坂坡七进七出叙事包装）。
- 每日挑战、好友排行榜（纯单机数据，无付费）。

## 5. 视觉锚点（Visual Anchors）

- **水墨国风（Ink-wash guofeng）**：宣纸米白底（#F4EFE3）、墨黑主笔（#1A1A1A）、朱红印章点缀（#C0392B）。禁用高饱和荧光色。
- **汉字即单位**：作战单位为居中的大号汉字（建议 48–72px 行楷/楷体），描边或墨晕。字形形变即其攻击动作，无需额外立绘。
- **字形动效语言**：攻击=字形按字义形变 + 墨迹拖尾；受击=字形抖动 + 朱红闪。统一"墨"的视觉语法。
- **技能特效语言**：以"水墨泼洒/笔锋扫过"表达，而非粒子爆炸；如赵云贯穿=一道墨痕横扫路径。
- **技术锚点**：单 `index.html`（或 index.html + game.js + data.js），Canvas 2D 绘制战场与字形（ctx.fillText + transform），DOM/CSS 绘制菜单与 HUD；原生 JS、零构建、双击本地打开即运行。

## 6. 关键设计约束（给工程的"宪法"）

1. **坐标系统一**：所有坐标以"网格列/行 (col,row)"为逻辑单位，渲染时 ×TILE 像素；路径 waypoints 用网格坐标描述，禁止硬编码像素路径。
2. **数据驱动**：单位/怪物/地图/波次全部来自 `data.js` 配置对象，新增内容只改配置不改逻辑。
3. **帧循环**：固定 `requestAnimationFrame` 主循环，逻辑用 delta-time（秒）驱动，与帧率解耦。
4. **零外部依赖**：不引入框架/字体 CDN；字体回退到系统 `KaiTi / STKaiti / serif`。
5. **可访问性**：字形最小 44px 触控热区；提供"减弱动效"开关（尊重前庭敏感玩家）。
