# GDD · 垂直切片验收清单（gdd-scope-slice）

> 模块：垂直切片（MUST）必须可玩的功能边界
> 用途：lean 评审的"完成定义"（Definition of Done）

---

## 1. 验收清单（逐项可勾）

### 关卡与路线（gdd-level-path）
- [ ] 单 `index.html` 双击本地浏览器打开即运行，零依赖零构建。
- [ ] 长坂坡网格（12×8, TILE64）与路径 waypoints 渲染正确，路径格高亮、禁止布防。
- [ ] 赤壁地图渲染（路径不同），可在选关进入（评审可默认解锁）。
- [ ] 长坂坡 8 波、赤壁 10 波按波次表 spawn，怪物沿 waypoints 行进。
- [ ] 过关（清完波次且阿斗存活）/ 失败（阿斗 HP≤0）判定正确。

### 文字动效（gdd-text-animation）
- [ ] 刀/枪/弓/骑 四兵种攻击各有可辨识字形形变（弧/刺/拉/冲）。
- [ ] 受击抖动 + 朱红闪在玩家单位与怪物上均生效。
- [ ] 弓（ranged）攻击生成可见弹道并命中结算。
- [ ] "减弱动效"开关可用。

### 技能特效（gdd-skill-vfx）
- [ ] 赵云可由 赵+云 合成（merge 配方）。
- [ ] 赵云技能键可见、就绪可点、冷却读秒。
- [ ] 点击后沿直线穿透多怪并结算 `damage*3` 伤害。
- [ ] 墨痕横扫 + 字形突进 VFX 可见，技能进入冷却并恢复。

### 文字与怪物模块（gdd-units-monsters）
- [ ] UNIT_DEFS / MONSTER_DEFS 为纯数据表，新增项不改逻辑。
- [ ] 4 基础兵种 + 3 怪物 + 1 Boss 数值与表一致。
- [ ] 击杀掉馒头、漏怪扣阿斗 HP。

### 合成与经济（gdd-merge / overview）
- [ ] 征兵消耗 3 馒头抽随机字（加权池）。
- [ ] 同字拖合升阶（t1→t2→t3），跨阶不合。
- [ ] 馒头经济闭环：初始12 / 击杀掉落 / 波次+4 / 过关+10。

### 流程（gdd-ux-flow）
- [ ] 菜单 → 选关 → 备战 → 对局 → 结算 完整流转。
- [ ] 备战可征兵/拖合/布防；出战后可实时操作。
- [ ] 暂停冻结逻辑；结算有胜负与重试/下一关。

## 2. 关键工程约束（落地红线，来自 concept §6）

1. **坐标统一**：一切坐标用 `(col,row)` 网格；像素 = `col*TILE + TILE/2`。路径用网格 waypoints，禁硬编码像素。
2. **数据驱动**：units/monsters/maps/waves 全在 `data.js`；加内容只改配置。
3. **帧循环**：`requestAnimationFrame` + delta-time（秒）驱动，与帧率解耦。
4. **零依赖**：不引框架/CDN；字体回退 `KaiTi, STKaiti, "Songti SC", serif`。
5. **可访问性**：字形 ≥48px、触控 ≥44px、"减弱动效"开关。

---

## 3. 切片显式不做（Out of Scope，避免范围蔓延）

- 不做联机对战、抽卡付费、账号系统。
- 不做张飞/黄忠技能实装（仅预留接口与数据）。
- 不做剧情动画、排行榜、成就系统（归 COULD 愿景）。
- 不做音效（音频交阮和鸣，切片可后置；视觉先行）。

## 4. 评审通过标准（lean）

- 主理人可单机打开 → 选长坂坡 → 征兵布防 → 合成赵云 → 放技能 → 清 8 波 → 见"过关"。
- 全程无需阅读文档即可上手（印证 P1 字以载战 / P3 零门槛）。
- 数值无明显失衡（无"只造一种单位必赢"的主导策略）。
