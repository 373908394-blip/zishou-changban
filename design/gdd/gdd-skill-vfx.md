# GDD · 技能特效（gdd-skill-vfx）

> 模块：武将技能触发逻辑 + 视觉表现（水墨语法）
> 状态：垂直切片 MUST 范围（赵云·贯穿 完整实现；张飞·眩晕 / 黄忠·箭雨 预留同接口）

---

## 1. 技能通用模型

```js
// hero skill 定义
{
  id, heroId, name,
  cooldown: 12,        // 秒
  trigger: 'manual',   // 切片：玩家点武将/技能键释放；就绪自动高亮
  vfx: 'pierce'|'stun'|'arrowrain',
  damageMult, range, shape
}
```

- 每个武将单位实例持有 `skillCdTimer`（初始=0，就绪=0 表示可放）。
- 释放条件：`skillCdTimer <= 0` 且 玩家点击该武将（或技能按钮）。
- 释放后：`skillCdTimer = cooldown`；播放 VFX；结算伤害。
- HUD 显示技能键：就绪（朱红高亮可点）/ 冷却（灰+读秒圈）。

## 2. 赵云 · 贯穿（Pierce）— 切片 MUST

- **触发**：玩家点击赵云单位（或赵云技能键）。
- **逻辑**：以赵云所在格为起点，沿"最近怪物方向所在的整行或整列"做穿透。切片简化为：**对赵云射程内一条直线上的所有怪物**造成 `damage * 3` 伤害（穿透，无视护甲/数量）。
  - 选取方向：朝向当前血量最高/最近的怪物，取该怪物所在的"行或列"（取与赵云共线且更近者）；若不与行列共线则按最近怪物方向取横/纵。
- **参数**：`cooldown=12s`，`damageMult=3`，作用线长 = 全场（穿透到底）。
- **VFX（水墨语法）**：
  1. 一道**墨痕横扫线**（宽 6px、朱黑渐变）从赵云格沿作用线快速掠过（0.3s）。
  2. 赵云字形 `translate` 沿该线突进 `+1*TILE` 再弹回（呼应"七进七出"）。
  3. 被命中怪物：`hitFlash` 朱红 + 短暂 `translate` 击退 `±6px`。
- **数据**：赵云基础 `damage=25`（见 units-monsters）→ 贯穿单跳 `25*3=75`。

## 3. 张飞 · 眩晕（Stun）— 预留接口（目标版 SHOULD）

- **逻辑**：以张飞格为中心 `radius=2` 格圆形 AoE，造成 `damage*1.5` 并 `stun 1.5s`（怪物 `speed=0`）。
- **VFX**：张飞字形放大 `scale(1→1.4→1)` + 一圈**墨色冲击波环**扩散（半径 0→2*TILE，0.4s）。
- **参数**：`cooldown=14s`。

## 4. 黄忠 · 箭雨（Arrow Rain）— 预留接口（目标版 SHOULD）

- **逻辑**：指定区域（点击选择或自动锁定怪物最密区）`radius=2` 格，1.2s 内落下多支箭，总 `damage*2` 分摊。有弹道（多 arrow projectiles 从天而降）。
- **VFX**：区域上方生成 8–12 支墨箭下落 + 落点**墨晕圈**。
- **参数**：`cooldown=10s`。

## 5. 平衡状态（防主导策略）

- 武将技能 CD 长（10–14s），且依赖稀有名碎片合成（见 merge），**不会取代布防**成为唯一解。
- 若赵云贯穿过强：下调 `damageMult` 至 2.5 或上调 CD 至 14s（在 skill-vfx 内调参，不改结构）。

## 6. 验收点（切片）

- [ ] 赵云技能键可见、就绪可点、冷却有读秒。
- [ ] 点击后沿直线穿透多怪并结算伤害。
- [ ] 墨痕横扫 + 字形突进 VFX 可见。
