# GDD · 玩家流程（gdd-ux-flow）

> 模块：用户操作流程 / 关卡选择 → 备战 → 对局 → 结算
> 状态：垂直切片 MUST 范围

---

## 1. 屏幕拓扑

```
[主菜单 MainMenu]
     └─ 开始游戏 → [关卡选择 LevelSelect]
                        ├─ 长坂坡(解锁) → [备战 Prep] → [对局 Battle] → [结算 Result]
                        └─ 赤壁(解锁，长坂通关后) → ...
[玩法说明 HowTo]（主菜单入口，弹层）
```

## 2. 各屏规格

### 2.1 主菜单（DOM）
- 标题《字守长坂》+ 水墨底。
- 按钮：**开始游戏**（→关卡选择）、**玩法说明**（弹层：拖合规则、赵云配方提示）。
- 无账号、无设置（"减弱动效"开关放此处，全局生效）。

### 2.2 关卡选择（DOM）
- 卡片列表：长坂坡（默认解锁）、赤壁（长坂胜利后解锁，切片可全解锁便于评审）。
- 每卡显示：地图名、最佳波次/是否通关（星标）、"进入"按钮。

### 2.3 备战（Prep，Canvas+DOM 叠层）
- 左侧/底部：**手牌区**（已征兵抽到的字，可拖）。
- 顶部 HUD：**馒头数**、**阿斗 HP**、**出战**按钮。
- 画布：渲染网格 + 路径（高亮）+ 已布防单位。
- 交互：
  - 点**征兵**（-3 馒头）→ 手牌 +1 随机字。
  - **拖字到非路径格** → 布防（生成单位实例）。
  - **拖字到同字同阶** → 升阶；**拖名碎片配对** → 合成武将。
  - 点**出战** → 进入 Battle（锁定布防，仍可实时征兵/合成）。

### 2.4 对局（Battle，主玩法）
- HUD（常驻）：馒头数、阿斗 HP（心形/墨点 ×10）、当前波次 `n/总`、暂停键。
- 武将技能键（若有赵云）：就绪高亮可点，冷却读秒。
- 怪物沿 path 行进；单位自动索敌攻击（字形动效）。
- 实时仍可：征兵、拖合、布防（空闲格）、点武将放技能。
- 波次推进：清空当前波 → `WAVE_GAP=6s` → 下一波（HUD 提示"第 n 波"）。
- 暂停：弹出"继续/重试/退出"，冻结主循环。

### 2.5 结算（Result，DOM）
- **胜利**：印章"过关" + 奖励馒头 +（若新解锁赤壁则提示）+ 按钮【下一关】【重玩】【返回】。
- **失败**：印章"败" + 按钮【重试】【返回】。
- 不弹窗广告、无付费。

## 3. 输入与可访问性

- 统一 **Pointer Events**（鼠标+触摸）：`pointerdown` 选中字 → `pointermove` 拖拽 → `pointerup` 释放（布防/合成/技能）。
- 触控热区 ≥ 44px；字形 ≥ 48px。
- "减弱动效"开关（主菜单）：关闭字形 rotate/scale/lunge，保留命中红闪与弹道。
- 关键状态有**文字+图形双提示**（如阿斗 HP 既显示数字也显示墨点），降低纯色觉依赖。

## 4. 状态机（顶层游戏态）

```
BOOT → MENU → LEVELSELECT → PREP ⇄ BATTLE → RESULT → (LEVELSELECT | PREP)
                              BATTLE ──pause──> PAUSED ──> BATTLE
```

## 5. 验收点

- [ ] 四屏（菜单/选关/备战/对局/结算）可完整流转，无死路。
- [ ] 备战可征兵/拖合/布防；出战后仍可实时操作。
- [ ] 暂停可用，冻结逻辑。
- [ ] 减弱动效开关全局生效。
